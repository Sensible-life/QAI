Agent Workflow

What the product actually does

  1. Discovery scans the page structure and entry conditions.
  2. Planner turns the chosen funnel into execution steps and fallbacks.
  3. Executor performs the browser actions while Evidence captures signals.
  4. Judge and Verifier promote failures into trusted release findings.
  5. Reporter turns the run into an explicit deploy or hold decision.

Design Constraint

What makes the agent trustworthy

  • Deterministic execution for low-level browser actions
  • Agentic planning and interpretation at the orchestration layer
  • High-severity findings require verification
  • Evidence is stored per step with screenshots and network issues
